Launchpad X controller for the Digitone II

Jank as a small USB host: a Novation Launchpad X plays and drives an Elektron Digitone II running the Wishes firmware, through the Digitone's live control, with Jank as the clock. This page installs the same Jank firmware as the plain Install page; nothing in the image is different. What it adds are the steps after the install: Jank set to USB host, the wiring, and what the Digitone needs. The modes and buttons: docs/launchpad.md and the Controller page of the Wishes site.

Beat follow (below) is not needed for this; leave its box unticked unless you want it for something else.

Flash from the browser

Chrome or Edge on a computer, a USB-C cable that carries data. One firmware for both devices: it finds out at the start which one it runs on. Its settings are kept.

  • It runs Jank already: plug it in as always and press Update Jank over USB MIDI. Chrome asks once to let the page use MIDI. The new firmware goes into the device's second slot; if it does not start, the old one comes back by itself. Keep the device plugged in until the page says done.
  • A new device (or one that does not start): put it in download mode first: unplug it, hold BOOT (the XIAO's B button) while plugging it in, then release. Press Flash a new device and pick the port the browser lists. When it is done, unplug it and plug it back in.

Beat follow

Beat follow needs a trained network. Jank's firmware does not carry one: the one it runs today is the beat model of the madmom project (CPJKU, Johannes Kepler University Linz), licensed CC BY-NC-SA 4.0: non-commercial use only. For commercial use, madmom's licence names its contact.

If you tick the box, this page fetches madmom's model from madmom's own repository, converts it here in your browser to Jank's format (the values unchanged) and writes it to your device with the firmware. Nothing is sent anywhere else, and this site never holds the model. Without it the device does everything else; beat follow stays off.

Next steps

  1. Set Jank to USB host, with Jank plugged into this computer. The button sends set usb host on Jank's control line over USB MIDI (as scripts/ctl.py set usb host does) and reads it back. It first talks to Jank until it has run 25 s, so a new firmware confirms itself before it can start as host. The setting is stored; on a computer Jank stays a USB device, so this page can still reach it. (A bare XIAO whose role was never chosen becomes host by itself; the button makes it explicit. The jank mini 3 needs it.)
  2. Unplug Jank from the computer. Connect it to the upstream (computer) port of a powered USB hub, and the Launchpad X and the Digitone II to the hub's other ports. Use a plain hub with USB ports only: Jank's USB controller has just enough channels for the hub, the Launchpad and the Digitone. Jank has no power of its own as host: a bare XIAO takes its 5 V from a hub that supplies its upstream cable, or from 5 V on its 5V pin, never while a computer is on its USB port (docs/usb.md). In host mode Jank has no USB link to a computer; plugged into a computer again, it starts as a device.
  3. The Digitone II needs the Wishes firmware with live control (live control stage 7, the test build v0.71.1-lp7, or later), and SETTINGS > SYSTEM > USB CONFIG > REMOTE CONTROL on (the default in Wishes). Start / stop led by the Digitone, the Session page's pattern cues and chains need live control stage 8, which is not out yet. See the Wishes site's Controller page.
