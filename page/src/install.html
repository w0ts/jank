AboutInstallDevice

Before you start

For the bare Seeed XIAO ESP32-S3, the stick. The firmware is built from the source; there is no ready-made download.

scripts/install_idf.sh    # once: ESP-IDF v5.5.6 (needs Python 3.13)
scripts/build.sh xiao     # makes jank.bin

Build files stay in the scratch folder $JANK_SCRATCH (default worktrees/jank-scratch/).

First install

A blank stick needs download mode once: hold BOOT while plugging it in. The first install of this build changes the partition table (two app slots) and the bootloader (rollback), so it is a full flash:

bash -c '. scripts/env.sh && cd "$JANK_SCRATCH/build-xiao" && python -m esptool --chip esp32s3 -b 460800 --before default_reset --after no_reset write_flash "@flash_args"'

Then unplug the stick and plug it back in. The BOOT hold is Seeed's usual way and was not tried for this page's steps.

Update by copying a file

A running stick shows a drive called JANK. No button, no download mode, no tool.

  1. Build: make build gives jank.bin. Or run make flash, which builds and does steps 2 and 3 for you.
  2. Copy jank.bin onto the JANK drive.
  3. The stick checks the image as it lands and restarts by itself once the computer has been quiet for 1.5 s. The drive comes back with UPDATE.TXT, which says what happened. macOS may say the drive was not ejected: that is normal here.

A wrong or damaged image is refused and the old firmware keeps running.

Update over USB MIDI

No drive, or the copy does nothing: make flash falls back to this by itself, or run it directly. Needs python-rtmidi. Stop playing first, and close other programs that use the stick's MIDI port.

python3 scripts/ota.py jank.bin

Rollback

A new image starts on trial. If it does not talk to a computer, the old one comes back: stay connected for about 20 s after an update, and press Connect on the Device page within two minutes. A crash or a power cut before that also puts the old image back.
