AboutInstallDevice

Ableton Link with no router

Jank brings computers, MIDI gear and modular gear into one Link session. The units send open Wi-Fi frames straight to each other on the group's channel: no router, no association, no password, no host. Units set to the same GROUP (1..9) hear each other.

It is the group mode of Optimist, the open firmware for the FM-1 synth. FM-1s running Optimist do this by themselves; the Jank device speaks the same air format, so whatever is plugged into it joins the group too.

What joins through it

  • A computer, over the network. The computer sees a USB network adapter on the group; Live, Bitwig or any Link app joins the same session as the FM-1s.
  • A computer or a USB device, by MIDI clock. USB-MIDI device for a computer, USB-MIDI host for gear with a USB port.
  • MIDI gear. MIDI outputs send clock, start and stop locked to the session.
  • Modular gear. Clock outputs, 5 V pulses.

It plays no sound: it follows the group's tempo and phase and sends them on.

Two devices

  • The stick: a bare Seeed XIAO ESP32-S3 in a computer or any USB host that speaks MIDI clock or Link. One button, one LED.
  • The Jank box: the same firmware on its own board, in a printed box: 3 MIDI outs, 1 MIDI in/out (TRS + DIN), 2 modular clock outs.

Put the firmware on a stick: Install. Run and watch one: Device.

Start and stop

Two layers that never touch each other: yours (Start / Stop) and the automatic one (low confidence, silence). The clock outputs run only when both say go. Start is the device's YES, a click of the stick's button, or the control page's play.
